## Included Changes

- Adds a dashboard production-readiness checklist derived from existing configuration and recorded operational evidence.
- Links operators directly to HTTPS, upstream relay, trusted-device, submission-policy, diagnostics, backup, and alert settings.
- Treats successful connectivity and test-email diagnostics as current only when they were recorded after the latest relay configuration save.
- Refreshes the public README and GitHub Pages site with real sanitized screenshots and clearer installation, safety, support, and contribution entry points.
- Adds structured issue forms, a pull-request template, contribution guidance, and safe support-reporting guidance.
- Keeps Pages version validation synchronized with `Directory.Build.props`.

## Safety Scope

- SMTP DATA durability behavior is unchanged.
- Trusted-network checks and submission-policy enforcement are unchanged.
- Queue state transitions, spool cleanup ordering, delivery authentication, and secret protection are unchanged.
- The readiness checklist derives state from existing configuration and operational records; it does not create a parallel setup state.
