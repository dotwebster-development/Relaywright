## Included Changes

- Windows installer overhaul:
  - Installer-managed install, update, uninstall, health verification, redacted diagnostics, and update rollback.
  - Structured SQLite, SQL Server, and MySQL database choices instead of raw connection-string entry.
  - Default/custom port flow with HTTPS, optional admin HTTP, and SMTP firewall port fields.
  - Focused firewall page with `LocalSubnet` default scope.
  - Final review page with redacted database and bootstrap settings.
  - Fixed service identity: service name `Relaywright`, display name `Relaywright - SMTP relay gateway`.
- Removed the installed standalone `Install-Relaywright.ps1` script from the Windows package.
- Updated Windows release validation to exercise installer-to-installer updates.
- Updated Windows installer docs, wiki drafts, release validation docs, and uninstall guidance.
- Shortened retention for large generated GitHub Actions handoff artifacts to keep release and deployment workflows from exhausting Actions storage.
